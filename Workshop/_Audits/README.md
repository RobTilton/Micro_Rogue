# Audit Storage
Updated: 2026-09-09

Optional storage for cross-Room evidence reports. Task-specific checks can remain in their owning Room. Audits record scope, inputs, method, findings, uncertainty and evidence; they do not grant mutation authority. See [Documentation Format](../Documentation_Format_README.md).

[Current_Audits](Current_Audits/README.md) contains current reports; [Archive_Of_Last_Resort](Archive_Of_Last_Resort/README.md) retains superseded reports when directed. Both start empty.
