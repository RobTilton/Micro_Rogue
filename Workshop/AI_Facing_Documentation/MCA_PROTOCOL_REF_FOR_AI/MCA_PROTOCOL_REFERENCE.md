# MCA Protocol Reference
Updated: 2026-09-09

## Rapid Shape

Terminology reference only. The [shared contract](../../AI_AGENTS_README/SHARED/.AGENTS.md) defines authority; this reference grants none.

| Term | Current meaning |
|---|---|
| MCA | Mutual Collaborative Alignment: trustworthy current-state transfer and bounded execution authority. |
| Alignment Check | Concise pre-write outcome, scope, affected locations, material constraints, and acceptance conditions. |
| Execute | Rob's explicit execution instruction following confirmed alignment. |
| DOTS | Deterministic Operational Traversal States: mandatory Room Box list and current traversal state. Checkpoints are `[Room]+[Table]+[Box]`. |
| DWR | Deep Work Rob: communication/workflow focus flag; no execution authority. |
| Sim Walk | Reason through the known system's directly relevant behavior and consequences. |
| Room / Table / Box | Bounded outcome / isolated working surface / compositional component or meaningful checkpoint. |
| ToolShed | Durable storage for proven reusable tools, parts, and builds. |
| SoF | Shits On Fire: human-directed return to a known-good repository state. Git recovery remains human-controlled; invocation API is undefined and must not be inferred. |

Halt And Request is retired from active MCA use. Ordinary discovery proceeds under existing authority. Material authority questions follow the shared contract.

For DOTS, document headers, state transfer, and closeout, use the [Room and documentation contract](../../AI_AGENTS_README/SHARED/MCA_ROOM_AND_DOCUMENTATION_CONTRACT.md).
