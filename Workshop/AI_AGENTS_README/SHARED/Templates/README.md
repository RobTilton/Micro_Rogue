# MCA Document Templates
Updated: 2026-09-09

Copy and fill these into the relevant Room; do not treat their placeholder checkpoints or authority fields as real state.

- [DOTS](DOTS_TEMPLATE.md): mandatory Box list and traversal record.
- [Current state](CURRENT_STATE_TEMPLATE.md): recovery context and component contracts.
- [Astra handoff](ASTRA_HANDOFF_TEMPLATE.md): validated mid-execution transfer.

Set the actual title, date, checkpoint, authority evidence and references. Omit inapplicable state-document sections. The [documentation-format README](../../../Documentation_Format_README.md) defines how to fill them; the [Room contract](../MCA_ROOM_AND_DOCUMENTATION_CONTRACT.md) governs their use.
