# Gear and Consumable Icon Checklist
Updated: 2026-09-14

Create one transparent PNG per base item below. These are inventory icons, not map hexes: no hex border, background, text, rarity frame or baked shadow outside the item. Use 128×128 canvases with consistent padding, readable silhouettes at 32–64 pixels, and the existing game’s painted pixel-art style. Keep the full object visible. Weapons can be diagonal. Supply separate PNGs named exactly by the ID; a labeled contact sheet is optional and separate.

First batch: health_potion.png, ration.png, swords_1.png, staffs_1.png, bows_1.png, shields_1.png, leather_body_1.png, leather_head_1.png, leather_arms_1.png, leather_legs_1.png, belts_1.png.

Draw one neutral material treatment per base item initially. Do not multiply this list by all materials or qualities; those visual variants can follow later. Names below identify silhouettes; duplicated material wording in the current catalog is a separate naming TODO.
